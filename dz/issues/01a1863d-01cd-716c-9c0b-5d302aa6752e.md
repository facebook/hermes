Compiling the VM with `-DHERMESVM_PROFILER_NATIVECALL` stops at the existing
`static_assert(sizeof(NativeJSFunction) == sizeof(SHNativeJSFunction))` in
`include/hermes/VM/Callable.h` (~line 617): the profiler adds counters to
the C++ class but not to the C mirror. Seen while changing
`NativeFunction::_nativeCall` for the RegExp builtin-exec fast paths
(D128480275); it fails the same way before that change. As a result the
profiler-only code in `NativeFunction::runNativeCallBody` (the callee reload
before updating `callDuration_`/`callCount_`) has never been compiled or
run.

Fix: add the profiler fields to `SHNativeJSFunction` under the same macro,
or move the counters out of the object; then build a profiler tree and run
check-hermes on it.
