`sh_unit_additional_memory_size` counts the `SHUnitExt::regExpCache` vector and
its entries. Because SH units have no native snapshot node, the entries appear
in no heap snapshot. A unit node, with child nodes like
`RuntimeModule::snapshotAddNodes`, would fix this. See `lib/VM/StaticHUnit.cpp`
(the memory size function) and the accounting section of
`doc/superpowers/specs/2026-10-26-regexp-bytecode-sharing-design.md`.
