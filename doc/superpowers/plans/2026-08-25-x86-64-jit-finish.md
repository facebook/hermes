# x86-64 JIT Un-gating, Goldens, CI and Perf (Milestone 6) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish the port per the spec's v1 definition: `test/jit`
un-gated and green on x86-64, an x86-64 dump baseline + golden workflow
established, the CI-shaped build/test matrix documented, and a perf
sanity measurement on a release build. Plus the spec corrections the
milestone-5 review mandated.

**Corrected premise (from the M5 final review, supersedes the spec's
Testing bullet):** `test/jit`'s 47 files contain NO assembly goldens —
all are behavioral or compile-status checks. Un-gating means dropping
the arm64-only gate and auditing arch-shaped assumptions, not moving
files. The real "golden" is the `jit-dump.sh` baseline workflow, which
x86 needs its own instance of (and whose canonicalizer is currently
arm64-syntax-only).
